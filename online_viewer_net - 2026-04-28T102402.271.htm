⚡ Setup Required

You need to connect a Firebase Realtime Database before the chat will work. It only takes ~3 minutes and it's free.

  1. Go to console.firebase.google.com and create a project
  2. Add a Web App and copy the config object
  3. Go to Build › Realtime Database › Create database (test mode is fine)
  4. Open chat.html in a text editor
  5. Replace the FIREBASE_CONFIG values at the top of the file with your own
  6. Change OWNER_PASSWORD to something secret
  7. Host on GitHub Pages and share the URL!

const FIREBASE_CONFIG = { apiKey: "AIzaSy...", authDomain: "your-project.firebaseapp.com", databaseURL: "https://your-project-default-rtdb.firebaseio.com", ... };

This notice disappears automatically once a valid Firebase config is detected.
