⚡ Setup Required

Connect a Firebase Realtime Database before the chat will work. Takes ~3 minutes and is free.

  1. Go to console.firebase.google.com and create a project
  2. Add a Web App and copy the config object
  3. Go to Build › Realtime Database › Create database (test mode is fine)
  4. Open chat.html in a text editor and replace FIREBASE_CONFIG
  5. Change OWNER_PASSWORD to something secret, then host on GitHub Pages!

const FIREBASE_CONFIG = { apiKey: "AIzaSy...", authDomain: "your-project.firebaseapp.com", databaseURL: "https://your-project-default-rtdb.firebaseio.com", ... };
